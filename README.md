# Vietnam Vocation 🇻🇳

9天7晚越南三城旅行攻略：岘港 + 会安 + 胡志明市

## 行程概览

| 日期 | 城市 | 行程 |
|------|------|------|
| 7/25 (Day 1) | 上海 → 香港 → 岘港 → 会安 | HX231 + HX548 转机，抵达会安 |
| 7/26 (Day 2) | 会安 | 古城漫游、秋盆河竹篮船、米其林餐厅 |
| 7/27 (Day 3) | 会安 → 岘港 | 返回岘港，山茶半岛、美溪海滩 |
| 7/28 (Day 4) | 岘港 | 巴拿山金桥、灵应寺 |
| 7/29 (Day 5) | 岘港 | 汉市场、龙桥、占族博物馆 |
| 7/30 (Day 6) | 岘港 → 胡志明 | VN7141 飞胡志明，范五老街 |
| 7/31 (Day 7) | 胡志明 | 统一宫、战争遗迹博物馆、邮局 |
| 8/1 (Day 8) | 胡志明 | 古芝地道、滨城市场 |
| 8/2 (Day 9) | 胡志明 → 上海 | HO1328 凌晨飞回浦东 |

## 特色

- **航班信息**：HX231 / HX548 / VN7141 / HO1328 完整航班时刻
- **住宿推荐**：Little Residence (会安) / Wink Danang Centre (岘港) / Saigon Hotel (胡志明)
- **米其林餐厅**：岘港9家 + 胡志明13家米其林推荐餐厅
- **自然美景**：山茶半岛、美溪海滩、巴拿山、秋盆河
- **摩托车租车**：岘港6家 + 会安4家租车店攻略
- **交互式地图**：64个Google地图标记点，支持分类筛选

## 查看

直接在浏览器中打开 `index.html` 即可查看完整攻略（含交互式地图）。

## 技术栈

- HTML / CSS 单文件设计
- Leaflet.js + Google Maps 瓦片
- JavaScript 交互式地图（64个标记、分类筛选、区域切换）
